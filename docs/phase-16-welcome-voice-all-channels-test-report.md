# 阶段 16：欢迎语音支持 Bot 所在的所有频道

## 本阶段内容

- “欢迎语音目标频道 ID”填写具体数字时，仍只在指定频道触发。
- 该配置留空时，改为对 Bot 当前所在的任意频道生效。
- 用户和 Bot 必须在同一个有效频道；Bot 不会因为用户加入其他频道而自动移动。
- 全局欢迎语音、启用状态和冷却规则保持不变。

在项目根目录执行：

```powershell
backend\.venv\Scripts\python.exe -m unittest discover -s tests -v
cd web
npm.cmd run build
```

本次实际结果：后端 `82` 项测试全部通过；前端 `npm.cmd run build` 成功。本阶段重点测试目标频道为空时同频道触发、不同频道跳过以及无效频道 ID 跳过。

## 手工测试步骤

1. 打开“设置 → TeamSpeak 配置”，上传并设置一条全局欢迎语音。
2. 将“欢迎语音目标频道 ID”留空并保存。
3. 让 Bot 进入频道 A，再让一个新用户进入频道 A，确认播放欢迎语音。
4. 将 Bot 移到频道 B，再让另一个新用户进入频道 B，确认也能播放欢迎语音。
5. 让用户进入一个 Bot 不在的频道 C，确认不播放，Bot 不自动移动。
6. 填写具体频道 ID后重复测试，确认只有指定频道触发。
