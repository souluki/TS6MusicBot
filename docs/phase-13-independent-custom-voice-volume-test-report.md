# 阶段 13：音乐与内置语音独立音量测试文档

## 1. 本阶段目标

解决以下问题：

- 音乐音量和上传的内置语音音量分开调节。
- 音乐播放中触发“你好”时，语音音量由独立配置控制，背景音乐仍降低 12 dB。
- 停止音乐后单独触发“你好”时，不再使用音乐音量；即使音乐音量是 10%，内置语音也能保持可听音量。

## 2. 配置位置

打开网页：

```text
http://127.0.0.1:5173/settings?group=teamspeak
```

在 TeamSpeak 配置中设置：

| 配置项 | 默认值 | 范围 | 作用 |
| --- | ---: | ---: | --- |
| 音乐播放器音量 | 当前播放器音量 | 0%～200% | 只控制普通音乐 |
| 内置语音音量（%） | 150% | 0%～300% | 只控制上传的内置语音；100% 为音频原始音量 |

建议先使用内置语音音量 150%。如果仍偏小，可逐步调整到 180% 或 200%；如果出现明显削波或失真，应降低数值。

## 3. 实现摘要

- `PlayRequest` 增加独立音量模式字段；普通音乐仍使用 Voice 的音乐音量。
- 内置语音单独播放时开启独立音量模式，绕过音乐音量。
- `PlayOverlayRequest` 增加语音增益；音乐播放中叠加语音时只放大语音，不改变背景降音逻辑。
- 配置项由后端设置定义提供，网页设置页会自动渲染，无需写死新的前端控件。
- 配置使用数据库中的运行时设置，不写入机器绝对路径，也不依赖固定部署目录。

## 5. 可复现手工测试

### 5.1 构建并启动 Voice

关闭旧 Voice 后，在项目根目录执行：

```powershell
cd voice-service
cargo build
.\target\debug\voice-service.exe 127.0.0.1:50051
```

保持该终端运行。Linux 部署使用对应的 `target/debug/voice-service`，不使用 Windows `.exe`。

### 5.2 启动后端和网页

另开终端，在项目根目录执行：

```powershell
backend\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8009
```

网页开发服务：

```powershell
npm.cmd --prefix web run dev -- --host 127.0.0.1 --port 5173
```

### 5.3 单独播放内置语音

1. 网页中把音乐音量调到 10%。
2. 把“内置语音音量（%）”设为 150%，保存并应用。
3. 在 Bot 当前 TS 文字频道输入已绑定的内置语音指令，例如：

   ```text
   !你好
   ```

4. 预期：语音可以正常听到，音量不随音乐的 10% 一起降低。
5. 将内置语音音量改为 100% 和 200% 后分别重复，预期声音随该配置增大或减小。

### 5.4 音乐中播放内置语音

1. 把音乐音量设为一个容易听出的值，例如 50%。
2. 播放一首音乐。
3. 输入 `!你好`。
4. 预期：音乐背景降低约 12 dB，语音使用“内置语音音量（%）”设置；语音结束后音乐恢复。

### 5.5 回归检查

- 普通歌曲的音量滑块仍然只改变音乐音量。
- `播放`、`暂停`、`继续`、`跳过`、`clear` 行为不变。
- 内置语音结束后，播放列表仍能自动继续播放。
- 修改内置语音音量后不需要重新上传音频；新一次触发立即使用新值。
