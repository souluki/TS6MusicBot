# TS6MusicBot 阶段 6 测试文档：需求边界回归

## 1. 本阶段目的

针对需求规格中的“关闭后恢复”“冷却”“不重复上传”“Bot 不自触发”等验收边界做补强，避免只验证正常路径。

## 2. 本阶段补强内容

### 欢迎语音

- 增加可配置的全局冷却，默认 10 秒。
- 增加可配置的单用户冷却，默认 300 秒，即 5 分钟。
- 使用 `unique_id` 作为用户冷却键；缺少 UID 时才回退到客户端 ID。
- Bot 自己不产生欢迎事件。
- Bot 不在目标频道时仍然跳过，不会自动移动。

### 动态资料

- 停止播放或切换到非网易云来源后，动态昵称恢复 `voice.ts3_nickname`。
- 关闭动态昵称时，当前歌曲也会异步恢复默认昵称。
- 关闭动态头像或离开网易云动态范围时，固定头像存在则恢复固定头像。
- 头像使用图片内容 MD5 去重，不同 URL 的相同图片不会重复上传。
- 快速切歌使用 generation 取消旧任务，旧歌曲不会覆盖新歌曲资料。

## 5. 可复现步骤

### 欢迎语音冷却

1. 配置欢迎目标频道和全局欢迎音频。
2. 让用户 A 进入目标频道，确认播放一次。
3. 让用户 A 在 5 分钟内再次进入，预期跳过。
4. 在全局 10 秒内让用户 B 进入，预期也跳过。
5. 等待全局冷却结束后，用户 B再次进入，预期可播放。

### 动态资料恢复

1. 开启网易云动态昵称和动态头像。
2. 播放网易云歌曲，确认昵称和头像变化。
3. 停止播放或切换到 B 站/QQ 音乐，预期昵称恢复默认；若配置了固定头像，预期头像恢复固定头像。
4. 关闭动态开关并保存，当前播放状态下预期异步恢复对应固定资料，不影响音乐和歌词。

### 图片去重

1. 连续播放使用相同专辑图的网易云歌曲，或使用不同 URL 指向相同图片内容。
2. 检查 Voice 日志，预期第二次不再发起新的头像上传。

## 6. 尚未完成的现场条件

当前机器没有监听 TeamSpeak `9987`、Voice gRPC `50051` 或 Web `8081` 的运行实例，因此真实 TS 用户进出、文件上传权限、头像呈现和音频听感仍需在用户启动服务后按阶段 4/5 文档现场验证。自动化和构建验证已完成。
