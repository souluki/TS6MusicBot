# 阶段 14：TS 歌词开关指令测试文档

## 1. 新增指令

在 Bot 当前 TS 文字频道输入：

```text
歌词 中断
```

关闭当前频道的歌词发送。

```text
歌词 播放
```

开启当前频道的歌词发送。

指令前可以加 `!`，例如 `!歌词 播放`。

## 2. 回复行为

指令执行后 Bot 必定回复提示：

- 正在播放时：`歌词已开启/中断；当前正在播放：歌曲名。`
- 暂停时：`歌词已开启/中断；当前已暂停：歌曲名。`
- 停止或队列为空时：`歌词已开启/中断；当前没有正在播放的歌曲。`
- 参数错误时：`用法: 歌词 播放 / 歌词 中断`

开启指令在当前有歌曲时会从当前播放位置重新安排歌词同步；当前没有歌曲时只保存开关，下一首播放时自动同步。

## 4. 手工测试

1. 启动 Voice、后端和网页。
2. 播放一首网易云歌曲，确认 TS 频道出现歌词。
3. 输入 `歌词 中断`。
4. 预期：Bot 回复当前播放状态，之后不再发送新的歌词。
5. 输入 `歌词 播放`。
6. 预期：Bot 回复当前播放状态，并从当前歌曲位置继续发送歌词。
7. 执行 `停止` 后再次输入 `歌词 播放`。
8. 预期：Bot 回复“当前没有正在播放的歌曲”；下一首歌曲开始后自动同步歌词。

## 5. 实现范围

- 复用已有 `voice.ts_lyrics_enabled` 配置。
- 关闭时取消当前歌词任务并递增任务代次，避免旧任务继续发送。
- 开启时重新读取当前播放项并安排歌词任务。
- “歌词”加入内置指令名，不会再被当作自定义语音指令。
