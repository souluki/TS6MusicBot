# Phase 10：网易云原词与翻译歌词合并测试报告

## 1. 需求

TS 当前文字频道中，原歌词和翻译歌词需要出现在同一条消息中，例如：

```text
♪ I love you
译：我爱你
```

## 2. 实现方式

- 网易云歌词接口同时读取 `lrc.lyric` 和 `tlyric.lyric`。
- 两组歌词分别解析为带时间戳的歌词行。
- 翻译行按照最近时间戳匹配原词，默认允许最大 0.75 秒误差。
- 合并后的消息使用原歌词时间戳，确保不会改变播放同步基准。
- 没有翻译、翻译时间戳无法匹配或翻译与原词相同的行，只显示原词。
- 没有时间戳时，使用逐行合并作为降级处理。

新增覆盖：

- 带时间戳的原词和翻译按时间合并。
- 原歌词时间戳保持不变。
- 无时间戳歌词逐行合并。
- 翻译缺失时保持原有行为。

2. 启动语音服务、后端和前端。
3. 只播放一首网易云歌曲。
4. 观察 TS 当前文字频道。

```text

```
