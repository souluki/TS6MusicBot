# 阶段 15：每条内置语音独立增益

## 本阶段内容

- 网页“自定义内置语音”列表的每一条语音包都增加独立的“语音增益”滑块。
- 范围为 `0%～300%`，`100%` 表示音频原始音量。
- 修改某一条语音包的增益后，只影响该语音包；音乐音量和其他语音包不受影响。
- 播放音乐时仍按原有逻辑降低背景音乐并混音；停止音乐后，内置语音仍使用自己的独立增益。
- 旧语音包没有独立设置时，暂时继承原有的全局“内置语音音量”设置，保证升级兼容。

## 手工复现步骤

1. 启动后端和网页，打开“设置 → TeamSpeak 配置”。
2. 上传两条不同的内置语音，例如指令 `你好` 和 `欢迎`。
3. 将“你好”设置为 `200%`，将“欢迎”设置为 `80%`。
4. 在 TS 文字频道分别输入 `!你好`、`!欢迎`，比较两条语音的音量。
5. 修改“你好”的增益后再次播放，确认“欢迎”的音量不变。
6. 同时播放音乐再触发两条语音，确认背景音乐按原有规则降低，语音包仍按各自增益播放。
